Network

IP changes take effect after reboot. Save to disk requires boot from the CF/IDE image (leapos-gateway.img), not the ISO alone.

EtherNet/IP assemblies (PLC connection)

Use these in Studio 5000 / RSLinx exclusive-owner connection:

  • Input assembly 100 (32 bytes) - gateway -> PLC
  • Output assembly 150 (32 bytes) - PLC -> gateway
  • Config assembly 151 (10 bytes)

LEAP peer mapping

Pick a discovered peer with Map, enable mapping, then Apply. Use Connect LEAP to bootstrap ownership (DISC -> MGMT -> OP) on demand. Use Save to disk so the mapping survives reboot.
